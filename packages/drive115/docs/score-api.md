# 115文件评分 API 文档

## 概述

115网盘的文件评分功能通过单一接口实现，支持对文件/目录进行 1-5 星评分和取消评分，同时支持批量操作。

文件列表中 `score` 字段表示当前评分，0 表示未评分。

---

## API 接口

### 设置文件评分 `/files/score`

```
POST https://webapi.115.com/files/score
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file_id` | string | 是 | 文件 ID，支持批量，多个用逗号 `,` 隔开 |
| `score` | number | 是 | 评分值（0-5），0 表示取消评分 |

**请求示例**:

```
file_id=3458739456796787776&score=4
```

**批量**:

```
file_id=id1,id2,id3&score=5
```

**取消评分**:

```
file_id=3458739456796787776&score=0
```

**响应**:

```json
{
  "state": true,
  "error": "",
  "errno": ""
}
```

失败时 `state` 为 `false`，`error` 包含错误信息。

---

## 评分取值

| score | 含义 |
|-------|------|
| `0` | 清除评分 |
| `1` | 1 星 |
| `2` | 2 星 |
| `3` | 3 星 |
| `4` | 4 星 |
| `5` | 5 星 |

---

## 文件列表中的评分字段

`GET /files` 响应中每个文件项包含 `score` 字段：

```json
{
  "fid": "3458739456796787776",
  "n": "新建文档.docx",
  "score": 4
}
```
