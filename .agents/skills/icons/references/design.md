# 自定义 SVG 设计

## 设计输入

- 用一句话定义对象、动作或状态，并明确使用场景和最小尺寸。
- 选择 2–3 个结构相近的 ionicons Filled 作为参照。
- 若语义依赖文字才能解释，先重新评估是否适合用图标表达。

## 造型

1. **轮廓优先**：先做单色外轮廓，再添加必要细节。
2. **关键线网格**：以 24×24 网格组织结构，最终采用光学校正。
3. **视觉重量**：与参照统一光学尺寸、面密度、圆角和构件粗细。
4. **正负形**：把孔隙和间隔纳入造型，避免小尺寸粘连。
5. **减法**：仅保留语义所需几何，减少路径和锚点。

## 输出合约

文件保存为 `apps/monkey/src/icons/custom/<kebab-case>.svg`，根节点保持：

```svg
<svg viewBox="0 0 24 24" fill="currentColor" xmlns="http://www.w3.org/2000/svg">
  <path d="..." />
</svg>
```

- 默认使用闭合填充路径，不混用 `stroke`。
- 仅在层级不可缺少时使用 `fill-opacity`。
- 不写 `width`、`height`、`class`、内联样式、硬编码颜色、渐变或滤镜。
- 图形不接触 viewBox 边缘，并按参照校正留白和重心。
