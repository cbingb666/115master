# UI 源码持有 Design Token 事实

`@115master/ui` 源码是 Design Token 具体值的唯一事实来源；agent skills 只规定 token 的语义分类、命名、使用边界和修改流程，并引用源码。颜色、圆角与基础控件尺寸直接采用 daisyUI 的语义变量，不创建同义的 `--ui-*` 别名；UI 命名空间只补充 daisyUI 缺失的公共概念，组件适配变量保持内部。首版 token 只覆盖迁移组件的真实需要，局部值仅在出现第二个消费者或形成跨组件语义时提升。颜色、圆角、阴影、层级、动效和材质等共享视觉决策必须使用 token；能说明只服务单一布局的局部几何值可以保留在调用层，不机械禁止所有任意值。这样既让构建产物直接消费同一套值，也避免 skill、CSS、重复 token 层与预设体系各自维护具体数值而发生漂移。
